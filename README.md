# Upwind Security Platform

Production-ready secure GitOps platform with defense-in-depth security.

## Stack
- **Infrastructure**: Terraform, AWS (VPC, EKS, ECR)
- **Container Security**: Trivy, Multi-stage builds, Non-root users
- **GitOps**: ArgoCD
- **Secrets**: AWS Secrets Manager + External Secrets Operator
- **Monitoring**: Prometheus + Grafana
- **CI/CD**: GitHub Actions
